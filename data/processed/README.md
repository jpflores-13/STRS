# data/processed/

Processed files used for analyses and figure generation.

For each subdirectory, corresponding data can be retrieved from the following GEO Accession numbers:
- Hi-C: Hi-C (GSE310051) & Degron Hi-C (GSE312288)

- RNA: GSE310049

- CUT&Tag: GSE310047

```
processed/
├── hic/ # Hi-C matrices & calls
├── rna/ # RNA-seq quantification & DE
└── cutntag/ # CUT&Tag signal & peaks
```
All coordinates reference **hg38**
