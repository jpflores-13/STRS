---

## Regenerate Figures

```bash
# All figures
make

# Individual figure
make fig1

# Main figures only (1-5)
make main

# Supplementary figures only (S1-S3)
make supplementary
```

Or run scripts directly:
```bash
Rscript scripts/figures/Figure1.R
```

---

## Source Scripts

Each figure is generated by its corresponding script in `scripts/figures/`:
- `Figure1.R` → `Figure1.pdf`
- `Figure2.R` → `Figure2.pdf`
- etc.

See `scripts/figures/README.md` for script details.
