# Figures

Final manuscript figures as publication-quality PDFs.

---

## Contents

```
figures/
├── Figure1.pdf    # Hyperosmotic stress induces large-scale rewiring of chromatin interactions.
├── Figure2.pdf    # Sorbitol-induced loops are more punctate, form weaker chromatin domains, and peak at 1 hour of treatment.
├── Figure3.pdf    # CTCF, cohesin, and YAP1 are retained at gained loop anchors following hyperosmotic stress.
├── Figure4.pdf    # Sorbitol-induced chromatin loops require RAD21 and are enriched at promoters.
├── Figure5.pdf    # Sorbitol-induced loops are associated with transcriptional changes.
├── FigureS1.pdf   # Hyperosmotic stress induces predominantly de novo looping that frequently reuses pre-existing anchor sites and favors long-range interactions.
├── FigureS2.pdf   # 3D chromatin domain organization under hyperosmotic stress: compartments, saddle plots, and TAD insulation.
├── FigureS3.pdf   # Hyperosmotic stress reduces nuclear volume (collaborator-provided figure, no R script in this repo).
├── FigureS4.pdf   # CTCF and cohesin binding is selectively retained at anchors of sorbitol-induced chromatin loops.
├── FigureS5.pdf   # Covariate matching controls for loop size and interaction frequency in gained loop comparisons.
├── FigureS6.pdf   # CUT&Tag binding scatter plots for CTCF, RAD21, and YAP1 in control vs. sorbitol conditions.
├── FigureS7.pdf   # CTCF retention analysis: log2FC vs. CPM bins, PWM score, RAD21 fold-change, and promoter density.
├── FigureS8.pdf   # H3K27ac differential analysis at loop anchors: MA plot, anchor overlap bar plot, and anchor vs. between-anchor density.
├── FigureS9.pdf   # CTCF and RAD21 auxin-inducible degron validation: microscopy images and nuclear GFP intensity quantification.
├── FigureS10.pdf  # Enhancer-promoter loop enrichment and CRE-CRE APA analysis of H3K27ac peaks at gained loop anchors.
├── FigureS11.pdf  # HOMER motif QQ scatter plots and ENCODE ChIP-seq overlap for CTCF, RAD21, and ATAC loop anchors.
├── FigureS12.pdf  # Hyperosmotic stress induces DoG transcription at select loci; RNA-seq signal tracks for SAMD4A and KDM6A.
└── GraphicalAbstract.pdf  # Graphical abstract submitted with the Cell Reports manuscript.
```

> **Note:** `GraphicalAbstract.pdf` is a static submission asset, not generated by a script in `scripts/figures/`.
> `FigureS3.pdf` was generated by a collaborator outside this repo (nuclear volume quantification from confocal imaging); there is no corresponding R script under `scripts/figures/`.

## Regenerate Figures

```bash
# All figures
make

# Individual figure
make fig1

# Main figures only (1-5)
make main

# Supplementary figures only (S1, S2, S4-S12)
make supplementary
```

Or run scripts directly:
```bash
Rscript scripts/figures/Figure1.R
```

---

## Source Scripts

Each figure is generated by its corresponding script in `scripts/figures/`:
- `Figure1.R` → `Figure1.pdf`
- `Figure2.R` → `Figure2.pdf`
- etc.

See `scripts/figures/README.md` for script details.
