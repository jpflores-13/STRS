##  Cluster Characteristics

Clusters were identified using K-means clustering (k=3) on variance-stabilized, normalized RNA-seq count data from HEK293 eGFP-YAP cells under hyperosmotic stress.

### Clustering Method
- **Algorithm:** K-means (k=3, nstart=25, seed=123)
- **Input data:** Normalized expression matrix, averaged across biological replicates
- **Scaling:** Row-scaled (z-score normalization)
- **Selection criteria:** Genes with significant temporal changes (|log2FC| > 2, padj < 0.05 at any timepoint)

## Generation Details

### Source Script
**`scripts/analysis/rnaseqTimecourse_clusters_heatmap.R`**

### Input Data
- DESeq2 LRT results: `data/processed/rna/timecourse/output/deseqObjs/LRTtimecourse.rds`
- Timepoints analyzed: 0h (baseline), 1h, 3h, 6h, 9h, 12h, 24h
- Biological replicates: 2 per timepoint (combined by averaging)

### Gene Selection Criteria
1. Significant in likelihood ratio test (LRT) across all timepoints
2. Strong fold change at ≥1 timepoint: |log2FC| > 2
3. Adjusted p-value: padj < 0.05
4. Log fold changes shrunk using `apeglm` to reduce noise

### Output Files
- **Gene lists:** `tables/cluster_*_genes.csv` (this directory)
- **Heatmap:** `plots/rnaseqTimecourse-km-heatmap.pdf`
- **Clustering object:** `data/processed/rna/timecourse/output/clustering_results.rds`

## Usage

### Load Gene Lists in R

```r
# Load individual cluster
cluster1_genes <- read.csv("tables/cluster_1_genes.csv")

# Load all clusters
cluster_genes <- lapply(1:3, function(i) {
  read.csv(paste0("tables/cluster_", i, "_genes.csv"))
})
names(cluster_genes) <- paste0("Cluster_", 1:3)
```

## 🔄 Reproducibility

To regenerate these files:

```bash
# 1. Ensure processed RNA-seq data exists
ls data/processed/rna/timecourse/output/deseqObjs/LRTtimecourse.rds

# 2. Run clustering script
Rscript scripts/analysis/rnaseqTimecourse_clusters_heatmap.R

# 3. Files will be created in tables/ directory
ls tables/cluster_*_genes.csv
```

**Dependencies:**
- DESeq2 ≥ 1.42.0
- ComplexHeatmap
- tidyverse
- See `renv.lock` for complete package list

## File Format Details

### CSV Structure

```csv
gene_id
ENSG00000000003
ENSG00000000005
ENSG00000000419
...
```

- **Column:** `gene_id`
- **Format:** Ensembl gene ID (e.g., ENSG00000000003) or gene symbol
- **Order:** Matches row order in clustered heatmap
- **No duplicates:** Each gene appears in exactly one cluster
